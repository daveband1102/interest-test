高三電腦專業取向探索測驗｜GitHub Pages 發布說明

1. 登入 github.com，新增 Public repository，例如 computer-interest-test。
2. 選擇 Add file → Upload files，將本資料夾 index.html 上傳到儲存庫根目錄並 Commit changes。
3. Repository → Settings → Pages。
4. Build and deployment 選 Deploy from a branch；Branch 選 main、資料夾 /(root)，按 Save。
5. GitHub Pages 部署完成後，可在 Pages 設定頁看到正式網站連結。通常格式為 https://使用者名稱.github.io/computer-interest-test/ 。
6. 將正式網址做成 QR Code 提供學生掃描。

注意：這是靜態網頁；測驗結果只存在學生當次瀏覽器中，無自動集中回收或教師後台。需要集中統計時應另外串接表單／資料庫，並加入資料蒐集告知及必要的隱私措施。
